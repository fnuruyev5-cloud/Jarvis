# F2 JARVIS Tools Add-on

Frontend add-on for an existing F2 JARVIS web project.

## Included
- Floating tools panel
- Browser camera preview and JPEG capture/download
- Copy buttons for code blocks, including dynamically rendered blocks
- Nano Banana image generation UI calling `/api/generate-image`
- Spline launcher
- MediaPipe / TensorFlow.js presence check

See `INSTALL-AZ.txt` for Azerbaijani installation instructions.

This add-on does not replace your existing app files or server. The image generation feature requires a working backend endpoint and a server-side `COMETAPI_KEY`.
