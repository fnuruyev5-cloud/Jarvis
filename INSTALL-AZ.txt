F2 JARVIS TOOLS ADD-ON — QURAŞDIRMA

1) ZIP faylını aç.
2) f2-tools-addon.css və f2-tools-addon.js fayllarını GitHub layihənin əsas qovluğuna yüklə.
3) index.html faylını aç. </head> bağlanışından əvvəl əlavə et:

<link rel="stylesheet" href="./f2-tools-addon.css">

4) index.html faylında </body> bağlanışından əvvəl əlavə et:

<script src="./f2-tools-addon.js"></script>

5) GitHub-a commit et. Render avtomatik deploy etmirsə, Manual Deploy et.

FUNKSİYALAR
- Ekranın sağ-altında JARVIS TOOLS paneli.
- Kamera açmaq, şəkil çəkmək və JPG yükləmək.
- Kod bloklarında “Kodu kopyala” düyməsi.
- /api/generate-image endpoint-i ilə AI şəkil yaratmaq.
- Spline 3D səhifəsini açmaq.
- MediaPipe və TensorFlow.js kitabxanalarının mövcudluğunu yoxlamaq.

VACİB
- Kamera üçün HTTPS və brauzer kamera icazəsi lazımdır.
- AI şəkil yaratmaq üçün server.js-də /api/generate-image endpoint-i olmalı, Render Environment-də COMETAPI_KEY təyin edilməlidir.
- Şəkil API-si ödənişli ola bilər; CometAPI tarifini yoxla.
- Bu əlavədə MediaPipe/TensorFlow.js modelləri avtomatik yüklənmir. Yalnız kitabxanaların olub-olmadığı yoxlanır; real face/hand/object tracking üçün model inteqrasiyası ayrıca tələb olunur.
- API açarını heç vaxt index.html və ya JavaScript frontend faylına yazma.
- Mövcud server.js, style.css və hologram/canvas dizaynını silmə; bu ZIP yalnız əlavə fayllardır.
